# Automation capability matrix

Generated by `scripts/gen_automation_docs.py` from the node registry, the adapter registry and the bundled template files. Do not edit by hand.

## Node types (each has a registered runtime handler)

| Node | Produces | Side effects | Network | Risk | What it does |
|---|---|---|---|---|---|
| `authorization_check` | scope | none | no | low | Resolves the target against policy and fails closed if it is private, unauthorised or out of scope. |
| `adapter_query` | findings | read network | yes | medium | Runs ONE registered source adapter against the checked target through the normal search machinery (policy applied again). |
| `enrich` | findings | read network | yes | medium | Runs one adapter on targets discovered upstream (bounded, each re-checked against scope before use). |
| `transform` | findings | none | no | low | Merges datasets and/or filters findings by predicate or confidence. Pure and local. |
| `case_findings` | findings | none | no | low | Reads findings already stored in this case (local; restricted items are never included). |
| `sensor_health` | findings | none | no | low | Reads the status of devices registered in the Hardware module (simulated, replay or owned receivers). Never transmits. |
| `case_gaps` | findings | none | no | low | Lists open requirements and unverified claims of this case as items. |
| `deduplicate` | findings | none | no | low | Removes repeated findings by a stable key. Pure and local. |
| `correlate` | links | none | no | low | Suggests links between datasets that share a value. Suggestions only: nothing is merged. |
| `snapshot_diff` | diff | write local | no | low | Compares a dataset with the last successful baseline: new, removed, changed and uncertain. |
| `condition` | bool | none | no | low | Evaluates a comparison; downstream nodes may depend on it through `when`. |
| `analyst_review` | review | none | no | low | Pauses the run until a person approves or rejects. |
| `evidence_save` | evidence | write local | no | low | Stores a dataset as a hashed evidence item in the case. |
| `notification` | notification | external | no | low | Raises an in-app/desktop notification (or a webhook to a destination approved in Settings), de-duplicated. |
| `report` | report | write local | no | low | Writes an encrypted case report (restricted material withheld). |
| `delay` | none | none | no | low | Waits a bounded time (at most 5 minutes). |
| `file_ingest` | evidence_file | write local | no | low | Parses a user-supplied file offline, stores it hashed, extracts observations and classifies it. |
| `error_handler` | notification | external | no | low | Runs only when another step failed; raises a notification. |

Triggers: `manual`, `schedule` (5-field cron + IANA time zone), `event` (`new_finding`), `file`. `webhook` triggers are not implemented (the application runs no inbound listener).

Error codes: `UNSUPPORTED_ADAPTER`, `INVALID_GRAPH`, `SCOPE_EXPIRED`, `APPROVAL_REQUIRED`, `RATE_LIMITED`, `CREDENTIAL_MISSING`, `SOURCE_UNAVAILABLE`, `TIMEOUT`, `RUN_CANCELLED`, `PARTIAL_RESULT`, `SCOPE_DENIED`, `OFFLINE`, `UPSTREAM_FAILED`, `INTERRUPTED`, `INTERNAL`, `UNSUPPORTED`.
