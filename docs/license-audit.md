# Licence audit

Generated by `scripts/license_audit.py` from the lockfiles' installed metadata. It lists every runtime/build-graph dependency that ships and calls out anything that is not plainly permissive. **An inventory, not legal advice.**

Totals: 42 Python, 9 web, 415 Rust. Flagged for human review: **2**.

MPL-2.0 packages (e.g. certifi) are counted as permissive here: it is file-level weak copyleft and they are redistributed unmodified.

Build-time tools that do not ship in the artefacts (PyInstaller, Playwright, ruff, mypy, vitest, ...) are outside this inventory. PyInstaller is GPL-2.0-or-later *with a bootloader exception* that permits distributing the frozen output under any licence; that exception is the reason it was chosen, and it should be re-read before any commercial redistribution.

Bundled third-party **tools** (Subfinder, Sherlock, Maigret, amass, theHarvester, ExifTool, Tesseract ...) are never redistributed: they are discovered on the user's machine and run as separate processes. See `docs/source-licenses.md`.
