# Quick start (five minutes)

Everything here is in the default, simple mode. Nothing needs the Advanced workbench.

1. **Open Home** and press **New investigation**.
2. **Choose A person or A business**, then type or paste what you know: an email, a username (`@name`), a website, a name, a phone number or a business name. One is enough. You can paste several at once; each is typed automatically and you can correct the type.
3. **Say whose information it is and why**, and tick the authorization statement (it is recorded as a 30-day authorization). Researching someone else on a client's behalf needs written consent: use the Advanced workbench's Authorization tab for that.
4. Press **Review plan**. You see, before anything is sent:
   - **Will run now**: public registries and archives.
   - **Will run if you approve**: sources that send an input to a third-party site. Pressing Investigate approves exactly the ones still ticked. Untick any you do not want.
   - **Needs an API key**, **Not available** and **No supported source**: not run, each with the reason. A phone number or a name on its own cannot be searched automatically; it is stored (masked) and nothing is sent.
5. Press **Investigate**. The page shows honest progress. It follows leads at most 2 steps out, uses at most 100 source runs and stops after 30 minutes. You can **Pause** or **Stop** at any time; what was collected is kept.
   If a provider's limit is reached (for example VirusTotal's public API allows 4 lookups a minute), the remaining checks **wait** and the page reads *Waiting for provider limits* with an estimated time. Nothing needs you; they continue by themselves, even after a restart. Settings → *Provider usage* shows what is left and when it resets. Nothing is ever bought.
6. **Read the Overview.** *Independently corroborated* means evidence that is not the subject's own statement. *Self-attested* means you said so. *Possible* means a lead that nobody has confirmed. *What could not be done* lists every method that did not run and why. “Nothing found” is only ever said for a source that actually ran.
7. **Open Review** (or the banner on Home). For each lead choose **Mine / confirmed**, **Not mine**, **Unsure** or **Need evidence**. A preview shows the effect first. “Mine” is recorded as your own attestation, not as proof. Evidence is attached only if you pick it, and only if it is about the same site. You can undo a batch.
8. **Improve coverage** by adding another email, username, website, business or owned domain under *Improve coverage* on the Overview. A found handle is only researched after you confirm it and choose **Use as input**.
9. **Save a report** under *Report*: a simple brief or an expert export, each citing its evidence. Restricted values are never included.

**Advanced mode** (top bar or Settings) shows the full workbench: every case tab, tools, graph, imports, automations, DARKINT and Setup. Turning it on or off never changes stored data, and every link into a case keeps working.
