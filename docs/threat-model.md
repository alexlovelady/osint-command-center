# Threat model (implemented controls only)

Legend: **T** = covered by an automated test · **M** = mitigated in code, no dedicated test · **O** = open / not mitigated.
Test names refer to `tests/`. Assets: evidence and case data, API token, vault key, backup passphrase, the user's network position.
Adversaries considered: a malicious web page or local process, hostile target content (pages, files, tool output, model output,
plugins), another local user, a curious cloud AI provider, and tampering with data at rest. Not considered: a root/admin-level
attacker on the same machine, hardware attacks, a compromised OS credential store.

| Threat | Control | Status |
|---|---|---|
| Local API reachable by others | 127.0.0.1 only; ephemeral port when packaged; per-launch 256-bit bearer token, constant-time compare; every route except `/health/live` is 401 without it | **T** `test_unauthenticated_requests_rejected_except_liveness` (walks the OpenAPI schema) |
| Hostile web page calling the loopback API | Origin allow-list (403), no CORS wildcard, no cookies, `Cache-Control: no-store`, CSP on API responses | **T** `test_disallowed_origin_blocked` |
| Cross-case / cross-user access | Membership check in every case-scoped route (404, not 403); AI retrieval, MCP and search filter by case in the query; admin gate on global operations | **T** `test_second_actor_*` / `test_other_actor_*` across api, fusion, workflows, humint, hardware, ai, mcp, plugins |
| Command injection via targets/tool output | Strict target parsers; fixed argv, never a shell; target is one argv element; `-`-prefixed values rejected | **T** `test_target_text_is_one_argv_element_never_executed` and parser tests |
| SSRF (loopback, private, link-local, metadata, v4-mapped v6, rebinding, redirects, scheme tricks, huge bodies) | `ip_is_public`, per-hop validation, IP pinning, redirect cap, size cap; plan-time rejection of private targets; plugins and update check use the same client | **T** `tests/security/test_ssrf_and_injection.py`, plugin and update tests |
| Path traversal / zip slip / tar tricks | Hash-derived vault paths; containment checks; symlinks refused; restore into a new dir; SigMF/DOCX archives checked for unsafe members and size/entry limits before use | **T** vault, backup, SigMF, DOCX tests |
| Evidence tampering | sha256/sha512 at ingest; re-hash on read/download/backup; mismatch → 409 + audit; encrypted objects authenticate their hash as AAD | **T** `test_tampered_vault_object_detected_on_download`, `test_swapping_two_ciphertexts_is_detected` |
| Audit-log tampering | Hash chain verified by doctor | **T** — detects edits/deletions of events, **not** a whole-file rewrite by an attacker with disk access |
| Stored XSS | Markdown with raw HTML off + `nh3` allow-list; UI uses server-sanitized HTML only; report renderers escape all fields | **T** `test_notes_markdown_is_sanitized` |
| Hostile documents (PDF/DOCX/Office macros, archives) | Static byte/regex inspection only; no XML parser, no rendering, no fetching of embedded links; ZIP entry/size limits; macros and active content are reported as flags | **T** `tests/integration/test_docs_import.py` |
| Hostile pcap/firmware/SBOM/STIX files | Bounded parsers that never execute, unpack-and-run or emulate; malformed input rejected before storage | **T** `test_intel_imports.py` |
| Secrets leakage | Keys only in the OS credential store; never in artifact URLs, findings, audit metadata or responses; key-less adapters make no request | **T** reputation, OpenCorporates and Censys tests |
| Plaintext evidence at rest | AES-256-GCM vault, key custody in the OS credential store, fail-closed `required` mode | **T** `tests/integration/test_encryption.py` |
| Plaintext **database** and **reports** at rest | SQLCipher 4 (AES-256) database keyed from the master key; reports stored as AES-256-GCM `.enc`; wrong/missing key = refuse to start, never recreate; plaintext migration is verified before the swap and the leftover is overwrite-deleted on request | **T** `tests/integration/test_db_encryption.py` (ciphertext on disk, wrong key untouched, migration with FTS, failure leaves the original, backup restored under a different key, reports encrypted). Residual: the key sits in the OS credential store, so anything running as you can read it; plaintext exists in memory and in files you download |
| Stolen/forged backup | scrypt + AES-256-GCM chunked container; wrong passphrase, truncation and reordering detected | **T** `test_backup_container_roundtrip_wrong_passphrase_and_truncation` |
| Unauthorized active scanning | Active adapters absent from the default registry; need `OSINTCC_ENABLE_ACTIVE=1`, an unexpired unrevoked scope authorization for the target, and per-run confirmation; policy re-checked at execution | **T** `test_policy_audit.py`, workflow/plugin active tests |
| Offline mode leaking requests | Policy denies network adapters; zero HTTP asserted | **T** |
| Prompt injection into the AI feature | Retrieved text is untrusted data; model output is parsed as a schema; only citations to retrieved same-case evidence count; proposals are never executed and carry no verification authority | **T** `test_prompt_injection_cannot_start_collection_expand_scope_or_forge_verification`, `test_fabricated_and_foreign_citations_are_rejected_not_displayed_as_verified` |
| Data exfiltration to a cloud model | Off by default; case must allow it; exact payload preview; one-time token bound to that payload; restricted items withheld; transfers audited | **T** `test_cloud_*` |
| Overreach by an MCP client | Scoped to `--cases`; read-only; writes wait for out-of-band single-use approval bound to an argument hash; approved actions still pass policy | **T** `tests/integration/test_mcp.py` |
| Malicious or buggy plugin | Out-of-process, minimal env, no network of its own, host-mediated allow-listed fetches, schema-validated output, tree-hash review, quarantine, timeout and output cap | **T** `tests/integration/test_plugins.py`. Limits on memory/CPU are POSIX-only; Windows relies on timeout, output cap and the allow-list |
| Hardware misuse (transmit, covert capture) | Receive-only driver protocol, ownership assessment + law acknowledgement, purpose, visible stop, duration limit, restricted GPS positions | **T** `tests/integration/test_hardware.py` (simulation/replay only) |
| Mass / covert monitoring | Schedules default disabled, explicit confirmation, back-off and self-disable, person-monitoring acknowledgement, audit trail | **T** workflow tests |
| Misleading output (coincidence taken as fact) | Correlations are suggestions with caveats; confidence labels with published rules; contradictions preserved; reports state limitations and say custody notes are not legal certificates | **T** `test_briefing.py`, fusion tests |
| Forged update | Ed25519-signed manifest against a pinned key; malformed/forged → 422; never downloads or installs | **T** `tests/integration/test_updates.py`. No update server or key exists yet |
| Malicious or tampered tool download (first-run Setup) | Pinned SHA-256 per artifact (publisher checksums, re-verified when the catalog was built); https-only, publisher-host allow-list incl. every redirect hop, size cap; hash checked before extraction; member-wise extraction refusing traversal, symlinks and bombs; Python tools from `--require-hashes` locks in private virtual environments; no admin rights; exact URLs shown and `confirm` required; offline mode refuses; audit events | **T** `tests/integration/test_setup.py` (mismatch deleted, unlisted host/redirect refused, traversal/symlink/bomb, confirmation, offline, non-admin). Real installs ran on Windows and Linux. Residual: PyPI/GitHub/SourceForge could serve a bad file only if it also matches the pinned hash |
| Third-party tool misbehaviour (phone-home, helper processes) | Fixed argv, scratch cwd, stripped environment, output cap, timeout kills the whole process tree, Maigret auto-update/recursion off | **T** `test_timeout_kills_helper_processes_too`; verified against the real Sherlock/Maigret/Subfinder/ExifTool |
| Backend left running after the shell dies | Windows kill-on-close job object; Linux `PR_SET_PDEATHSIG` on shell→backend and backend→child; graceful shutdown endpoint | Windows verified by hand; **Linux verified in a container**: SIGKILL of the shell left 0 backends |
| Supply chain | Locked dependencies (`uv.lock`, `pnpm-lock.yaml`, `Cargo.lock`); `pip-audit`, `pnpm audit`, `cargo audit` clean at release time (Linux-only transitive Rust warnings: `proc-macro-error` unmaintained, `glib` unsound — not in the Windows build); SBOMs in `docs/supply-chain/`; licence inventory; secret scan of tree and binaries | M — results are a point in time (2026-10-24); CI to repeat them has **never run** |
| Tauri capability scope | Empty capability set, no plugins, strict CSP, handshake parser rejects malformed lines, token delivered by command not URL, kill-on-close job object (Windows) | **T** Rust parser tests + manual launch. CSP/capabilities not fuzzed; Linux has no process-group equivalent yet |
| Covert egress by the app | Loopback-only server; no telemetry code; adapters use the SSRF-guarded client; previews, offline mode and unconfigured updates make no request; Setup downloads only after confirmation | **T** zero-HTTP assertions; **Linux packet capture** shows no DNS/TCP/UDP from the shell or backend; Windows connection attribution shows none from our processes. **Open:** Microsoft's WebView2 runtime (Windows) connects to Microsoft addresses on its own; the Windows `pktmon` capture names the destination as `substrate.office.com` |
| Regression in network behaviour | Start-up egress self-check on every launch (connection sampling of our process tree, audited, shown in the UI); packet-capture scripts for deeper checks | **T** `tests/integration/test_egress_selfcheck.py`; real runs on Windows (`engine_only`) and in the frozen smoke test |
| Unsigned binaries | None — releases are unsigned | **O** (SmartScreen warns; publish SHA-256) |
| Prompt injection through evidence or documentation reaching the Copilot | All retrieved material is wrapped as untrusted data (`<data>`, `<doc>`, `<tool_result>`); text that could close or fake the envelope is neutralised; the model's only side effects are *proposals*; tool blocks are parsed only from the model's own reply | **T** `test_evidence_text_cannot_inject_instructions_or_close_the_data_envelope`, `test_tool_block_parsing_is_strict` |
| Copilot acting without consent | Action tools create a `CopilotProposal` with a preview; execution is a separate authenticated request by the owner, uses the stored arguments (not client-supplied ones), is single-use, re-checks role, case status and policy at execution, and is audited; hardware, key and secret operations are not exposed at all | **T** `test_start_search_is_only_a_proposal_until_a_person_approves_it`, `test_rejecting_does_nothing_and_proposals_cannot_be_widened_or_cross_cases`, `test_policy_is_rechecked_at_approval_and_offline_blocks` |
| Copilot claiming something it did not do / inventing features or evidence | Wording that claims an action is flagged and a notice appended; citations that do not match a record shown to the model are removed; questions about the app that the documentation does not cover get a deterministic "not documented" answer without calling the model; an empty case gets "no stored findings" without calling the model | **T** `test_a_reply_that_claims_an_action_is_flagged_and_nothing_ran`, `test_undocumented_features_get_a_not_documented_answer_without_calling_the_model`, `test_empty_case_gets_no_invented_findings_and_no_model_call` |
| Cloud disclosure through the Copilot | Cloud profile needs case permission and a transfer token bound to the exact payload hash; restricted items never go to the cloud; one call per approval (no tool rounds) | **T** `test_cloud_models_need_case_permission_and_an_exact_payload_approval` |
| Uncensored local model | The model is untrusted: policy, scope, approval and role checks are in code and run the same whatever the model says | **T** the approval tests above run with a model that tries to act |
| Corrupted conversation store | Messages are parsed defensively; damaged rows are skipped and counted, never rendered | **T** `test_corrupted_conversation_records_are_skipped_not_fatal` |
