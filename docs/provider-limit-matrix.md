# Provider limit matrix

Generated by `scripts/gen_provider_matrix.py` from `backend/osintcc/quota/catalog.py`: these are the limits the dispatcher enforces, not a copy of anyone's marketing page.

Every figure is a **default**. Where a provider reports its own limits (urlscan.io, Brave, GitHub response headers; the urlscan.io quotas endpoint through Settings → Provider usage → Test) the provider's number replaces the default
for that window. A 429, 401, 402 or 403 from the provider always overrides this table. No provider here was exercised live in this build: see [provider-quotas.md](provider-quotas.md) for what is fixture-tested.

## Reset rules and known limitations

### VirusTotal
- Plan assumed: public (free) API.
- Credential name in the credential store: `virustotal`.
- Resets: Daily quota resets at 00:00 UTC. Requests are spaced at least 16 seconds apart so four never go out at once.
- The public API is for personal, non-commercial use only; it is not suitable for a business workflow.
- These are the documented public-API limits. A real account may have less; a 429 or a quota error from VirusTotal overrides them.
- Terms/limits page: https://docs.virustotal.com/reference/public-vs-premium-api

### urlscan.io
- Plan assumed: free account (limits read from the operator's account screen).
- Credential name in the credential store: `urlscan`.
- Resets: Fixed windows: they reset at the full minute, the full hour and 00:00 UTC. Each action (search, result retrieval, each kind of scan) has its own budget. Only successful (HTTP 200) requests count.
- The figures are from the operator's own account screen and can differ on another account; Fusion reads the real limits from the quotas endpoint and from response headers when it can.
- Without a key urlscan applies much smaller limits to the address; the budgets above assume a key.
- Terms/limits page: https://docs.urlscan.io/pages/api-rate-limits

### Censys
- Plan assumed: Free (100 credits per month, one concurrent action, lookup endpoints only).
- Credential name in the credential store: `censys`.
- Resets: Credits reset monthly (the first of the month, UTC, is assumed; confirm on the Censys account page). Each host, certificate or web-property lookup costs 1 credit.
- Authentication is a Personal Access Token sent as a bearer token to api.platform.censys.io. A token is never converted into an API-ID:secret pair.
- Exceeding the one-concurrent-action limit returns 429; the request rate limit returns 503. Both are treated as 'try again later', never as 'no result'.
- Terms/limits page: https://docs.censys.com/docs/platform-credits-free-starter

### Brave Search
- Plan assumed: read from the provider's response headers.
- Credential name in the credential store: `brave_search`.
- Resets: Brave reports the plan's per-second and per-month limits, what is left and when each resets in the response headers of every call. Until the first call the monthly limit is unknown, so only the per-second pace is enforced.
- There is no endpoint that reports the plan before the first call. 'Quota available' therefore stays unknown until a request has been made.
- Only successful requests are counted by Brave. Paid overflow is never enabled by Fusion.
- Terms/limits page: https://brave.com/search/api/

### SEC EDGAR
- Plan assumed: public (no key); contact string required.
- Resets: The SEC allows at most 10 requests per second; Fusion paces itself to 5 per second across the whole application.
- A contact (name and email) is required in the User-Agent. Without a valid one no request is sent.
- Terms/limits page: https://www.sec.gov/os/accessing-edgar-data

### Shodan
- Plan assumed: not used.
- Credential name in the credential store: `shodan`.
- Resets: Not used. Turning it on later needs your explicit confirmation after you have verified the account's entitlements.
- The capability Fusion would need is paid. It is excluded from automatic investigation planning.
- Terms/limits page: https://www.shodan.io/

### GitHub
- Plan assumed: anonymous.
- Resets: Anonymous search is limited to 10 per minute and other calls to 60 per hour per address; the response headers say exactly when each resets.
- Fusion does not send a GitHub token.
- Terms/limits page: https://docs.github.com/en/rest/rate-limit

### Gravatar
- Plan assumed: anonymous.
- Resets: Unauthenticated: 100 requests per hour; Fusion stays at 80.
- Terms/limits page: https://docs.gravatar.com/

### OpenPGP keyserver
- Plan assumed: anonymous.
- Resets: One lookup per minute.
- Terms/limits page: https://keys.openpgp.org/about/api

### Have I Been Pwned
- Plan assumed: paid key (operator's own).
- Credential name in the credential store: `hibp`.
- Resets: The rate depends on the key's plan; the provider's 429 response says how long to wait.
- Terms/limits page: https://haveibeenpwned.com/API/v3

### OpenCorporates
- Plan assumed: unknown.
- Credential name in the credential store: `opencorporates`.
- Resets: No quota is assumed for a free token; it is reported as unknown until the provider says otherwise.
- Commercial use needs a paid licence tier; Fusion cannot tell which tier a token is on.
- Terms/limits page: https://opencorporates.com/info/licence

### Internet Archive
- Plan assumed: public.
- Terms/limits page: https://archive.org/details/toc

### crt.sh
- Plan assumed: public.
- Terms/limits page: https://crt.sh/

### GDELT
- Plan assumed: public.
- Terms/limits page: https://www.gdeltproject.org/about.html
